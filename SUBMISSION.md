## Feature status

**Working end to end:**
- Create, rename, edit, autosave, reopen and delete documents.
- Rich text: bold, italic, underline, strikethrough, H1–H3, bulleted and numbered lists, quotes, undo/redo.
- `.txt` / `.md` / `.docx` import as new documents, with clear errors for unsupported files.
- Sharing with owner / editor / viewer roles: grant, change and revoke access. Owned and shared documents are shown separately.
- Persistence of content, formatting and sharing.
- Conflict-safe concurrent saves.
- Validation and error handling.
- 19 automated tests plus a browser e2e test.

**Incomplete / intentionally out of scope:**
- Real-time co-editing
- Real authentication
- Comments
- Version history UI
- Images and tables
- Import into an existing doc
- Export

**Next with 2–4 more hours:**
1. Version history with restore
2. Markdown / `.docx` export
3. A "new version available" notice for open editors
4. Import into the current document
5. CI running the e2e test
